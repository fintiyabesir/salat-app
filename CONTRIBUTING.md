# Contributing

Keep Salat narrow: prayer times, Qibla and calendar.

Before adding a dependency, check:
1. Is it required for one of those three jobs?
2. Is it free to distribute and free at runtime?
3. Does it add tracking, an account requirement, a backend dependency or a paid service?
4. Can the feature keep working offline?

Official-source adapters must document authority, URL, terms/usage constraints, refresh policy, attribution and failure behavior.

Do not commit private API keys or credentials.
